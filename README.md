# code-essentials

Most commonly used Julia functions by me. Short discriptions of module files in the repo:

| File              | Description                                                                                  |
|-------------------|----------------------------------------------------------------------------------------------|
| CommonImports  | Commonly used libraries and dependencies.                                                   |
| DataStruct     | Define core data structures.                                          |
| BaseIO         | Basic input/output routines.                                 |
| ArrayFunctions | Array-based computations and transformations (e.g., meshgridding, array rotations)|
| TurbAnalysis    | Functions for turbulence simulation analysis. |
| DecompMHD      | Implementing MHD mode decomposition.                                                         |
| DCFGSAFunctions   | Functions used for numerical tests of the modified DCF method using GSA polarization from [*Pavaskar et al. 2023*](https://doi.org/10.1093/mnras/stad1237). |
| SPAFunctions   | Functions used for numerical tests of the SPA++ method from [*Pavaskar et al. 2024*](https://doi.org/10.3847/1538-4357/ad5af5). |
| ShockFind      | Shockfind algorithm similar to [*Lehmann et al. 2016*](https://doi.org/10.1093/mnras/stw2015).             |
| tmpdec         | Decomposition tests and code similar to [*Makwana & Yan 2020*](https://doi.org/10.1103/PhysRevX.10.031021).          |
